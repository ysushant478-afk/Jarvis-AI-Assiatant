# Jarvis AI: Smart Voice Assistant

A fully functional Python-based voice assistant that interacts with the user, controls system applications, and fetches information from the web.

## Key Features

* **Interactive Chat:** Handles basic conversations like *"How are you?"*, *"Hello"*, and *"What is your name?"*.
* **System Control:** Open any installed application (Chrome, Notepad, VS Code, etc.) simply by saying its name.
* **Web Integration:** * **Google Search:** Ask *"Google"* and Jarvis will ask what you want to search.
    * **Wikipedia:** Get summarized information on any topic instantly.
* **Live Information:** * **Location Tracking:** Find your current location or any specific place on the map.
    * **Date & Time:** Get real-time updates on current date and time.
* **Smart Exit:** Recognizes stop commands like **"Exit"**, **"Bye"**, **"Quit"**, or **"Stop"** to shut down the program automatically.

## Tech Stack
* **Language:** Python
* **Main Modules:** `speech_recognition`, `pyttsx3`, `webbrowser`, `os`, `datetime`, `wikipedia`.

## How to Use
1.  Run the script in your terminal/IDE.
2.  Wait for Jarvis to start listening.
3.  Speak your command (e.g., "Open Chrome", "What is the time?", "Google").
4.  To close, simply say "Exit", "Bye", or "Quit".
